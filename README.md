Due to NDA, corporate security, and commercial intellectual property agreements, my core daily production repositories are private. However, I am the lead architect behind the following core SaaS products:

### TITAN Web — Enterprise ERP & POS
* Backend Stack: Built using robust PHP (Laravel / Custom MVC Framework) and Node.js microservices.
* Fiscal Integration: Engineered native, real-time connections with ARCA (ex-AFIP) Web Services for automated electronic invoicing (A, B, C tickets), points of sale, and instant taxpayer verification.

* Medical Infrastructure: Orchestrated an enterprise-level clinical workflow integrating Orthanc PACS via DICOM/MWL (Modality Worklist) and the OHIF Web Viewer for lossless cloud diagnostics.

* Club Administration: Full administrative backend tracking membership renewals, active gym subscriptions, recurring revenue metrics (MRR), workout template design, and digital medical check-ups.
